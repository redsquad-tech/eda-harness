# Acceptance Testbench Workflow

For a specification-to-Cadence workflow, use these skills in order:

1. `spec-to-verification-plan`
2. `spec-to-hdl21-mock-dut`
3. `verification-plan-to-implementation-plan`
4. `implementation-plan-to-testbenches`
5. `test2report` — optional, only when the user requests an ngspice report
6. `control-to-maestro`
7. `maestro-to-cadence`
